# 0003. 上下文树与纯函数 resolve

## 状态

已采纳，2026-10-23。

## 决策

会话的上下文存成一棵有向树，不是可变数组。会话表上显式记录 head 指针；分叉就是新建
一个会话行共享祖先，不复制数据。

**模型看到的一切由一个纯函数决定。**

```
resolve(head, policy) -> ResolvedContext
```

它没有 IO、没有时钟、没有随机数。给定同样的 head 与 policy，输出逐字节相同。发送给
模型的消息数组永远不会在别处被拼装。

**解析结果由四段构成。**

```
[固定层] 系统提示 + 工具目录快照 + AGENTS.md 冻结版本
[帧]     若干条摘要，按时间顺序
[最近]   最近若干轮原文
[当前]   当前待办与工具结果
```

**帧对检查点是弱引用。** 帧里记的检查点编号允许悬空（快照可能已被挤出保留窗口）。
解析时检查该检查点是否仍可到达，并注入三态之一：一致、磁盘更旧不可达、磁盘更新可达。
这条保证上下文回退之后模型不会误以为文件还是摘要描述的样子。

**固定层在会话开始时冻结。** `AGENTS.md` 或工具目录发生变化时不改写固定层，而是追加
一条系统事件说明变化。压缩是唯一允许重建固定层的时点，因为压缩本身已经作废了前缀缓存。

**读集要单独记录。** 每个工作区维护"路径 → 最后读到的内容哈希 + 读取者"的表。工具写入
时反查，向读过该文件的会话推送一条上下文事件。租约只解决"谁先写"，通知不到"刚读完、
已释放租约、正在推理"的那个 agent，两件事必须分开。

## 理由

**回退与压缩是同一个操作的两个投影。** 回退是把 head 指回祖先，压缩是造一个新帧并把
head 指到新节点。两者都只是改变 resolve 的输入。只要解析是纯函数，这两件事就自动获得
同一套语义、同一套测试、同一套调试手段。

**纯函数带来四件很难得的能力。** 能逐字节复现任意历史轮的输入（调试长程问题必需）；
能在不调用模型的情况下单测压缩逻辑；能让两个子 agent 共享祖先而不复制数据；能算出
前缀哈希从而判断供应商的前缀缓存是否会命中。

**显式 head 是分叉的前提。** 如果靠"最后一行"确定位置，任何并发追加或回滚都会让分支
静默丢失。head 的比较并交换更新是分叉正确性的唯一保障。

**三态漂移通知是这套设计的必要补丁。** 上下文回退不改文件（见 0005），因此"模型记忆"
与"磁盘现实"必然会出现方向不一致。不告知模型的后果是它基于错误前提继续操作，而且这类
错误不会报错，只会安静地写坏代码。

## 后果

好的方面：分叉便宜；压缩与回退同源；调试可复现；缓存可计算。

代价：

- **解析必须永远保持纯。** 一旦有人为了方便在读路径里读一次文件或取一次当前时间，
  replay 就永久失真。这条由 0001 的依赖门部分保证，其余靠评审。
- **固定层冻结意味着磁盘变更只能靠事件传播。** 比"每次重读 AGENTS.md"多一步，但换来了
  缓存命中。
- **帧的弱引用让"摘要描述的世界"可能已不存在。** 三态通知把这个问题降级为一次提示，
  但用户仍可能遇到"摘要说改了 X，实际已经回滚到 X 之前"的情况。
- **读集表会随会话增长。** 需要按会话回收，且它本身不是权威数据（丢了只会少一条通知）。

需要重新审视的信号：如果解析耗时成为瓶颈（超过 20 毫秒），先查是否在读路径里做了
本应在写入时完成的工作，而不是加缓存。

## 被否决的替代方案

**上下文存成可变数组，压缩就是就地截断加插入摘要。** 这是绝大多数 agent 工具的做法，
实现最简单，也不需要树。不选的理由是它无法支持三件事：回退到历史点（数组已经截断，
信息不可逆丢失）；逻辑分叉（没有祖先可共享）；带上下文的子 agent（只能复制整个数组，
成本随上下文线性增长）。这三件事都是本项目的核心主张。

**帧对检查点用强引用，快照不淘汰则帧失效。** 语义上最干净：摘要描述的世界必然可达。
不选的理由是它把两个本该正交的回滚绑在一起——快照保留窗口一满，上下文就必须跟着失效，
上下文管理的自由度被快照预算绑住。弱引用加三态通知用很小的复杂度换回了正交性。

**把 AGENTS.md 与工具目录每次重新读入作为固定层。** 简单且永远最新，但每次文件变化都会
作废整个前缀缓存，长程任务的输入成本会显著上升。追加事件用一行系统消息换到同样的信息，
代价小两个数量级。

**把工具检索的结果放进工具目录（也就是固定层）。** 看起来自然，实际会让固定层每轮变化，
前缀缓存全失效。检索结果必须进消息，不能进工具定义。这条在 0008 里也会提到，因为它是
同一个约束的两个面向。
