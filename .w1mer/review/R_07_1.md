# Review R_07_1

Status: ok

## Conclusion

07.1 的拓扑类型与依赖无环校验正确实现了 unit 拓扑的纯逻辑部分，十条验收全过。`UnitId` 是校验过的标签名义类型（小写字母数字加连字符、非空、首尾不连字符、不连续连字符），与 systemd unit 命名同型，`Ord` 是标签词典序供最小堆排序，`Hash` 供边集合去重。`DepKind` 三变体（Requires/Wants/After）在图结构里方向相同，种类只记录不消费。`Topology` 的 `find_cycle` 用 DFS 三色标记在三种边的并集图上找环，撞灰节点即提取闭合环路径（首等于尾），归一为从最小标签起。`startup_order` 先查环，无环则做 Kahn 加最小堆，产出词典序最小的拓扑序，入度按并集邻接表数（同一对 unit 的多种类边只算一次，与松弛次数一致）。`lease ↔ tools` 的双向记号落成单方向边（lease 依赖 tools，tools 先启动），在 mod.rs 文档注释写明裁决。07.1 不新增依赖、不建表、不碰 tokio，版本推进到 0.1.42。

## Findings

- `UnitId` 解析校验与 systemd unit 命名同型：空串被拒、首尾连字符被拒、连续连字符被拒、大写与非 ASCII 被拒不自动转换。检查顺序是空串、首尾连字符、非法字符、连续连字符，与验收口径一致。测试 `unit_id_rejects_empty_label`、`unit_id_rejects_leading_or_trailing_hyphen`、`unit_id_rejects_consecutive_hyphens`、`unit_id_rejects_invalid_characters` 守着每条边界，`unit_id_accepts_lowercase_label` 守着合法标签被接受。
- 三色标记在三种边的并集图上找环正确：`union_adjacency` 建 `target -> dependents` 的并集邻接表（BTreeSet 去重多种类边），DFS 从最小标签起按标签序推进，撞灰节点即从栈顶回溯到灰节点、补回起点、反转成依赖方向、归一为从最小标签起。环路径闭合（首等于尾），测试 `cycle_returns_closed_path` 显式断言 `first() == last()`。
- 入度按并集邻接表数而非原始边集数：`startup_order` 的入度从 `adj.values()`（并集邻接表）数，同一对 unit 的多种类边只算一次，与松弛次数一致。若入度按原始边集数（含种类），多种类边的入度会偏大，松弛只减一次，节点永远不为零，顺序不完整。测试 `multiple_kinds_between_same_pair_are_legal` 守着这条：加 `requires` 与 `after` 两条同向边，断言顺序 `[b, a]` 完整。
- 词典序最小拓扑序真用最小堆：`startup_order` 用 `BinaryHeap<Reverse<UnitId>>`，`Reverse` 把最大堆翻成最小堆，每次取最小标签出堆。测试 `stable_order_is_lexicographically_smallest` 在菱形里断言 `b` 在 `c` 前（`b` 标签小于 `c`），守着"词典序最小"而不是"某个确定序"。
- 环归一化不破坏闭合：灰节点总是环中最小标签（DFS 从最小 unit 起按标签序推进，环中最小节点必最先被访问），所以 `rotate_left` 的 `turn` 恒为零，闭合性（首等于尾）保持。测试 `cycle_returns_closed_path` 与 `self_dependency_is_a_cycle` 守着闭合性。
- `lease ↔ tools` 落单方向边：mod.rs 文档注释写明"双向记号落单方向边，lease 依赖 tools，tools 先启动"，测试 `seven_unit_minimal_topology_is_acyclic` 按这个方向实例化（`add_requires(lease, tools)`），断言 `tools` 在 `lease` 前。
- 三种边都参与无环判定：测试 `all_edge_kinds_participate_in_cycle_check` 建 `wants` 与 `after` 环（无 `Requires`），断言被检出，守着"无环校验对三种边的并集判定，不是只对 `Requires`"。
- 重复边幂等：边集合是 BTreeSet，按 `(target, dependent, kind)` 自然去重，加两次同边只算一次。测试 `duplicate_edge_is_idempotent` 守着。
- 自依赖是环：环路径 `[A, A]`，闭合。测试 `self_dependency_is_a_cycle` 守着。
- 空拓扑与孤立 unit 合法：空拓扑返回空顺序，孤立 unit 返回自身顺序。测试 `empty_topology_is_legal` 与 `isolated_unit_is_legal` 守着。
