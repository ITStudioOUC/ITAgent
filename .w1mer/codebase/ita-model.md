# ita-model — 模型供应商适配

> 当前状态：空壳。`crates/ita-model/src/lib.rs` 只有模块文档注释与 `#![deny(unsafe_code)]`、`#![deny(missing_docs)]`，没有实现代码。

## 预定职责

模型供应商适配：报文归一化、流式聚合与用量记账。只做数据变换——把供应商报文归一化成上下文模型认识的形状，把流式增量聚合成完整响应，按供应商回传的字段算出可记账的用量。

## 依赖

`ita-kernel`（见 `STRUCTURE.md` 依赖边表）。

## 边界

- 不发起网络请求、不持有凭据、不写数据库；连接与鉴权都在 server 的模型代理里。
- 字节与时间戳由调用方传入。
- 供应商回传的 usage（输入/输出/cache 读写 token）必须落事件表，这是成本账本的唯一来源。
