# ita-workflow — 工作流定义、静态检查与节点状态推导

> 当前状态：空壳。`crates/ita-workflow/src/lib.rs` 只有模块文档注释与 `#![deny(unsafe_code)]`、`#![deny(missing_docs)]`，没有实现代码。

## 预定职责

工作流定义、静态检查与节点状态推导：解析工作流定义、在载入与拉取时检查写集冲突、从节点完成记录推导节点状态。

## 依赖

`ita-kernel`（见 `STRUCTURE.md` 依赖边表）。

## 边界

- 只做纯数据变换：不执行节点、不碰存储。
- 完成记录由 server 在事务内追加，节点执行由 worker 与执行器完成，信号只是低延迟提示。
- 节点完成状态由事件推导，完成记录在事务内写入（ADR 0011）。
