# EPIC 03 拆分为二级子任务

由并发探索产出，作为派发依据。每个子任务应在单批次内完成：一个验收行为、不超过八个文件、不超过约四百行。

| 子任务 | 标题 | 验收 | 主要文件 | 依赖 |
|---|---|---|---|---|
| 03.1 | Command AST 类型与目标提取 | 手工构造的 AST 提取出排序去重的读写路径列表 | crates/ita-kernel/src/command/{mod,ast,error}.rs | 无 |
| 03.2 | 词法扫描：词、引号与算符 | 含引号参数与重定向的命令得到预期 token；;、&&、&、$()、反引号、未引号通配符各返回带偏移的拒绝 | crates/ita-kernel/src/command/lex.rs | 03.1 |
| 03.3 | heredoc 状态机与十项失败 | 未终止、残留、超 1 MiB、非法分隔符、<<-、<<<、CRLF、行尾空格、空正文、未引号含展开字符十项各有断言 | crates/ita-kernel/src/command/heredoc.rs | 03.2 |
| 03.4 | 语法装配：单命令与重定向 | 含 argv、重定向、heredoc 的输入产出完整 AST；a | b <<EOF 与双命令被拒 | crates/ita-kernel/src/command/parse.rs | 03.3 |
| 03.5 | 失败矩阵总表与诊断 | 表驱动集成测试在公共 parse() 上覆盖全部拒绝路径，错误含偏移与可操作建议 | crates/ita-kernel/tests/command_matrix.rs, src/command/error.rs | 03.4 |

## 说明

后续史诗的子任务为初步拆分，进入该史诗前由 Explorer 结合当时的代码重新核对；被证伪的子任务应删除或改写，不硬做。
