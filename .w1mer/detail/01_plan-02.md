# EPIC 02 拆分为二级子任务

由并发探索产出，作为派发依据。每个子任务应在单批次内完成，判据是一个验收行为、单次可验证、不混入无关改动；文件数与行数不作硬指标。

| 子任务 | 标题 | 验收 | 主要文件 | 依赖 |
|---|---|---|---|---|
| 02.1 | 根清单与内核空壳 | cargo metadata 只列一个成员，cargo tree -p ita-kernel 只剩自身，版本读到 0.1.0 | Cargo.toml, rust-toolchain.toml, crates/ita-kernel/{Cargo.toml,src/lib.rs} | 无 |
| 02.2 | 内核纯净门与依赖断言 | 临时在 kernel 写 std::time::Instant::now() 时 clippy 与脚本都失败，移除后都通过 | crates/ita-kernel/clippy.toml, crates/ita-kernel/src/lib.rs, .w1mer/scripts/check_kernel_purity.sh | 02.1 |
| 02.3 | CI 流水线五项门 | 格式、clippy、构建、nextest、纯净门本地顺序跑通 | .github/workflows/ci.yml | 02.2 |
| 02.4 | 基础层空壳与依赖方向 | build 通过，且 cargo tree -p ita-kernel 仍不含任何成员 | crates/ita-store, ita-proto, ita-sandbox, ita-exec 的 Cargo.toml 与 lib.rs | 02.3 |
| 02.5 | 上层空壳与依赖方向 | build 通过，server 依赖 store/proto/model/workflow，无成员反指内核 | crates/ita-tools, ita-model, ita-workflow, ita-server | 02.4 |
| 02.6 | 单二进制角色分发与 worker 空壳 | --version 打印 ita 0.1.0，master/worker/tool-host 退出 0，未知角色退出 2 | crates/ita-cli/{Cargo.toml,src/main.rs,src/role.rs,tests}, crates/ita-worker | 02.5 |
| 02.7 | 收口：文档同步与骨架验收 | STRUCTURE 去掉尚未创建并写实际路径，三件套全绿 | .w1mer/codebase/STRUCTURE.md, STACK.md, README.md | 02.6 |

## 说明

后续史诗的子任务为初步拆分，进入该史诗前由 Explorer 结合当时的代码重新核对；被证伪的子任务应删除或改写，不硬做。
