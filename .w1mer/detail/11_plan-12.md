# EPIC 12 拆分为二级子任务

由并发探索产出，作为派发依据。每个子任务应在单批次内完成：一个验收行为、不超过八个文件、不超过约四百行。

| 子任务 | 标题 | 验收 | 主要文件 | 依赖 |
|---|---|---|---|---|
| 12.1 | 归一化消息与工具定义类型 | 两家样本报文归一化后逐字段断言相等，且该 crate 无网络与异步依赖 | crates/ita-model/src/{lib,types,normalize,error}.rs | 无 |
| 12.2 | Anthropic 非流式编解码 | 请求只含单一 command 工具并带缓存断点，响应解出 tool_use、thinking 与 usage | crates/ita-model/src/anthropic/{mod,request,response}.rs | 12.1 |
| 12.3 | OpenAI 非流式编解码 | chat completions 的工具调用与缓存命中映射到同一类型，缺字段有明确错误 | crates/ita-model/src/openai/{mod,request,response}.rs | 12.1 |
| 12.4 | SSE 流式分帧与增量聚合 | 录制流聚合结果与非流式解析逐字段相等，usage 取流末值 | crates/ita-model/src/stream/{sse,aggregate}.rs | 12.1 |
| 12.5 | thinking 块不透明回传 | 带签名思考块原样回到同一条助手消息，压缩后整段丢弃并标记失效 | crates/ita-model/src/thinking.rs | 12.1 |
| 12.6 | usage 落事件表与账本查询 | 每次调用追加一条含四类 token 的不可变事件，可按工作区与模型聚合 | crates/ita-store/src/usage.rs, ita-server/src/usage_handler.rs | 12.1 |
| 12.7 | server 模型代理与非流式转发 | worker 只发消息数组，凭据注入与出网只在 server，载荷断言不含密钥 | crates/ita-proto/src/model_rpc.rs, ita-server/src/model/{proxy,credentials}.rs | 12.2,12.3,12.6 |
| 12.8 | 流式经 IPC 转发与取消传播 | worker 中途断开时上游请求被取消，已收 usage 仍落库且队列有界 | crates/ita-proto/src/stream.rs, ita-server/src/model/stream.rs | 12.4,12.7 |
| 12.9 | 单工具调用回合状态机 | 有 tool_use 则产出一条待执行命令，无则结束本轮，多个调用时报错记事件 | crates/ita-kernel/src/turn.rs | 12.1 |

本史诗的子任务为初步拆分，进入前由 Explorer 结合当时的代码重新核对；被证伪的子任务应删除或改写，不硬做。
