# EPIC 04 拆分为二级子任务

由并发探索产出，作为派发依据。每个子任务应在单批次内完成，判据是一个验收行为、单次可验证、不混入无关改动；文件数与行数不作硬指标。

| 子任务 | 标题 | 验收 | 主要文件 | 依赖 |
|---|---|---|---|---|
| 04.1 | Node、Frame 与 id 类型 | 三类 id 均为 26 字符 ULID，Frame 可持有允许悬空的检查点引用 | crates/ita-kernel/src/context/{ids,node,frame}.rs | 无 |
| 04.2 | 上下文树：head、分叉与 CAS | 过期 head 令牌的写入被拒，分叉共享祖先不复制，回退后再追加被识别 | crates/ita-kernel/src/context/tree.rs | 04.1 |
| 04.3 | ResolveInput 与预算结构 | 按 0018 字段可装入，构造时拒绝乱序帧与越界阈值，阈值只来自 Budget | crates/ita-kernel/src/context/{input,budget}.rs | 04.1 |
| 04.4 | 四段解析与逐字节复现 | 同一输入两次解析逐字节相同，顺序恒为固定层、帧、最近、当前 | crates/ita-kernel/src/context/{resolve,segment}.rs | 04.3 |
| 04.5 | 漂移四组合通知 | 四种组合各返回 0018 表中措辞，不可达格不推断方向 | crates/ita-kernel/src/context/drift.rs | 04.4 |
| 04.6 | 读集记录与陈旧写判定 | 同路径他人哈希不一致时判陈旧并列出读者，无记录判未知放行 | crates/ita-kernel/src/context/read_set.rs | 04.1 |

## 说明

后续史诗的子任务为初步拆分，进入该史诗前由 Explorer 结合当时的代码重新核对；被证伪的子任务应删除或改写，不硬做。
